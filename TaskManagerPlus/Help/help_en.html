Task Manager+ User Guide

Welcome to Task Manager+ – Your advanced system operations manager.

1. Processes Tab

Monitor all active processes and applications with real-time CPU and Memory priority tracking.

  • End task: Immediately terminate a process.
  • Right-click a process: Open advanced control menu.
    • Suspend Process: Freeze the process threads without losing unsaved data.
    • Resume Process: Unfreeze the suspended process.
    • Eco Mode: Lower the process priority to 'Idle' to save battery and system resources.

2. Smart Alerts Assistant

The system actively monitors Hardware temperatures and CPU utilization in the background. If an app runs abnormally hot or hogs CPU, a floating banner will appear suggesting actions like Kill or suspend.

3. Other System Tabs

  • Startup: Enable or disable applications running on boot.
  • Temperature: Monitor hardware thermometers, including SSD and GPU sensors.
  • Battery: Examine your laptop battery's wear level, discharge rate, and longevity tips.
  • Overview: See a summary of your daily computing habits.

4. Shortcuts

  • F1: Open this help manual.
