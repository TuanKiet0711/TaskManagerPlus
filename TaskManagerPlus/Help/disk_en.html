Using Disk Cleaner

The Disk Cleaner helps you instantly optimize storage and deeply analyze heavy files natively.

1. Drive Scanning

Select a drive letter from the dropdown box and press "Scan Drive". TaskManager+ automatically maps out the largest directories in a comprehensive Directory Tree and retrieves the top 50 heaviest files residing on the disk.

2. Deep Clean (Temp files)

Press the "Clean Temp" utility button to automatically target cache artifacts across the local machine user's AppData and Windows-wide Temp environment partitions. Storage is optimized dynamically and instantly.
