# TaskManagerPlusWeb (ReactJS)

Landing page giới thiệu app bằng ReactJS + Vite (web).

## Chạy dev

```bash
cd TaskManagerPlusWeb
npm run dev
```

## Build

```bash
cd TaskManagerPlusWeb
npm run build
```

## Download files

Đặt file tải xuống vào `public/downloads/` để các nút ở section **Download** hoạt động.
